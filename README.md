# コード読解リーダー（読み専用PWA）

iPad / Android のブラウザで、`git clone` 済みのフォルダを読み込み、AI（Claude）に解説してもらいながらコードを読むためのアプリ。
仕様は [SPEC.md](SPEC.md)、コードの読み方は [READING.md](READING.md)。

## できること（MVP）

| 仕様 | 実装 |
|---|---|
| §3.1 折り返しなし | 1行＝1表示行。長い行は横スクロール。行番号は左に固定され、常に行と1対1 |
| §3.1 横スワイプで画面が変わらない | スワイプにはスクロール以外何も割り当てていない。ブラウザの「戻る」スワイプ／Androidの戻るジェスチャーも画面を変えない |
| §3.1 表示設定 | ⚙ で文字サイズ・ダーク／ライト・行番号の表示 |
| （追加）折り返し表示 | ⚙ で「折り返さない／縦向きのときだけ折り返す／いつも折り返す」。折り返しても行番号は1行に1つで、続きはその行のインデント位置からさらに少し下げて表示（タブ・スペースどちらでも崩れない）。画面を回しても読んでいた行を保つ |
| （追加）スティッキー表示 | スクロール中、いま一番上に見えている行が属するブロック（class / def / if / for など）の先頭行を画面上部に残す。タップするとその行へ移動。インデントから判定するので言語を問わない。⚙ でオフにできる |
| （追加）検索・同じ単語のハイライト | 🔍 でファイル内検索（件数表示・▲▼で移動）。コード上の単語を長押し（PCはダブルクリック）で選ぶと、同じ単語をすべてハイライト |
| （追加）目次 | 📑 で関数・クラスの一覧（Markdown は見出し）を表示し、タップで移動。今いる位置に印が付く。Python / JS / TS / C / C++ / C# / HLSL / GLSL / Lua / シェル / Markdown に対応（書き方から拾う簡易判定） |
| （追加）大きなファイルの高速化 | 折り返さない表示では、画面外の行のレイアウトと描画を省く |
| （追加）重なる画面の操作 | チャット・サイドバー・設定画面は半透明のすりガラス表示。チャットは見出しの帯を上にスワイプで開き、下にスワイプで閉じる。サイドバーは中身の上でも横にスワイプすると閉じる（全体の 1/3 以上動かすか、はじくように速く動かすと閉じる。足りなければ元に戻る）。ピンチでの拡大は無効 |
| （追加）ファイル一覧の印 | AIと会話したファイルに 💬、しおりのあるファイルに 🔖 と件数を表示。フォルダには中の合計を表示するので、閉じたままでも分かる |
| （追加）チャットの区切り | 質問ごとに番号付きの目印を表示。右端の目盛りをタップするとその質問の先頭へ移動する（指でのスクロールでは吸い付かない）。返答中は質問を一番上に置き、先頭から読める |
| （追加）コードのフォント | コード表示は JetBrains Mono（日本語は M PLUS 1 Code）。⚙ で M PLUS 1 Code／端末に入っているフォント（Moralerspace・Source Han Code JP）／端末標準に切り替え可。フォントは `app/fonts/` に同梱（SIL Open Font License）。1ファイル版（standalone）には同梱しない |
| （追加）戻る操作 | Android の戻るジェスチャー／ボタン、iPadOS の端からのスワイプで、開いた・選んだ順の逆に1つずつ閉じる（行の選択、チャット、サイドバー、検索、設定などの画面）。何も開いていないときは「アプリを閉じますか？」の確認を出す |
| （追加）インデントの罫線 | インデントの深さごとに縦線を表示（2スペース／4スペース／タブを自動判定）。⚙ でオフにできる |
| §3.1 ハイライト | Python / JS / TS / C / C++ / C# / HLSL（.hlsl .usf .ush など）/ GLSL / Markdown / JSON / YAML ほか |
| §3.2 フォルダ読み込み | 「📁 フォルダを読み込む」で clone 済みフォルダを選ぶ。`.git` とバイナリは一覧に出さない。`READING.md` があれば最初に表示 |
| §3.3 読書位置・しおり | ファイルごとの位置を自動保存し、次に開くとそこから。しおりはメモ付きで、行番号の欄に色付きの印が出る。コードが更新されて行がずれても、同じ内容の行を探して付け替える（見つからないときは一覧に ⚠ を表示） |
| §3.4 範囲を選んで解説 | 行をタップ → 開始行、もう一度タップ → 終了行。「解説して」でファイル全体・選択範囲・READING.md を AI に渡す |
| §3.4 フォローアップ | チャット欄で続けて質問できる。選択範囲とコード表示は消えない。回答中の `L12` をタップするとその行へ移動 |
| （追加）アプリで聞く | 選択バーの「📋 アプリで聞く」で、指示・ファイル全体・選択範囲をまとめた質問文をコピーし、Claude / ChatGPT のアプリを開く。サブスクで使える（APIキー不要） |
| （追加）デバッグ表示 | ⚙ 設定、またはアドレス末尾の `?debug=1` でオン。画面右上の 🐞 からエラー・ログ・環境情報を見てコピーできる（`?debug=0` でオフ） |
| §3.5 プライバシー | APIキー・コード・会話は端末内だけに保存。AIへは端末から Anthropic API へ直接送信（間にサーバーなし） |

## 使い方

1. 公開URL（下記）を iPad の Safari / Android の Chrome で開き、共有メニューから「ホーム画面に追加」
2. Working Copy などで端末に clone しておいたフォルダを「📁 フォルダを読み込む」で選ぶ
3. 行をタップして範囲を選ぶ
4. どちらかで聞く
   - **📋 アプリで聞く**（サブスク向け・APIキー不要）: 質問文がコピーされるので、開いた Claude / ChatGPT のアプリに貼り付けて送る
   - **解説して**（アプリ内で回答）: ⚙ 設定の「使うAI」で次のどちらかを選び、APIキーを入れておく
     - **Gemini**: aistudio.google.com で無料の APIキー を作る。無料枠には回数制限があり、送った内容が Google のサービス改善に使われることがある
     - **Claude**: console.anthropic.com の APIキー（使った分だけ料金。Haiku 5.5 なら 1,000 行のファイル1回で 0.3 円ほどの見込み）

- iPad は **iPadOS 18.4 以降**の Safari でフォルダ選択ができます（それより前はフォルダを選べないため「ファイルを複数選んで読み込む」を使う。この場合フォルダ構造は残りません）
- 同じ名前のフォルダを読み込み直すと、中身だけ入れ替わります（読書位置・しおり・会話は残る）
- 2MB を超えるファイルは本文を保存しません（一覧に「大きすぎ」と出ます）
- `node_modules` や UE の `Intermediate` / `Binaries` / `Saved` などは読み込みません（⚙ 設定の「読み込まないフォルダ名」で変更可）

### 読み込みの流れ
フォルダを選ぶと、まずファイル名の一覧だけで画面を表示し、中身の読み込みと端末への保存は裏で進めます（保存中は画面上端に細い線が出ます）。
保存が終わる前でも、開いたファイルはその場で読み込まれます。保存が終わる前にアプリを閉じると、残りのファイルは開けないので、もう一度フォルダを読み込んでください。

### ファイル数が多いと読み込みが遅いとき
フォルダを選んだ直後は、ブラウザが中のファイルを**すべて**数え終わるまでアプリに渡してくれません（`.git` の中身も含む）。
この間はアプリから進み具合が分からないので「フォルダの中身を一覧にしています…」と表示します。速くするには:
- 読みたいサブフォルダ（例: `src`）だけを選ぶ
- clone するときに履歴を浅くする（`--depth 1`）。`.git` の中身が大幅に減ります

## ローカルで使う（公開しなくても動かせる）

GitHub の「Code → Download ZIP」などでこのリポジトリを手元に落とせば、次のどちらかで動きます。

### A. ファイル1つを開くだけ（PC向け・いちばん簡単）
`standalone/code-reader.html` をダブルクリックしてブラウザで開くだけ。インストールもサーバーも不要です。
このファイル1つにアプリ全部（ライブラリ込み）が入っているので、このファイルだけコピーして持ち歩くこともできます。

- PC の Chrome / Edge / Safari で動きます。AI への問い合わせもそのまま使えます
- iPad / Android では、ファイルアプリから HTML を開いてもアプリとして動かないので、B か公開版を使ってください

### B. PCでサーバーを立てて、iPad / Android から開く
PC に Python 3 が入っていれば:

| PC | 起動のしかた |
|---|---|
| Windows | `start-windows.bat` をダブルクリック |
| Mac | `start-mac.command` をダブルクリック（初回は右クリック →「開く」） |
| その他 | `python3 serve.py` |

起動するとPCのブラウザが開き、画面に `iPad/Androidで開く（同じWi-Fi）: http://192.168.x.x:8765/` と出ます。
同じ Wi-Fi の iPad の Safari でそのアドレスを開けば使えます（PC側のサーバーを起動している間だけ）。

- Windows で初回に「ファイアウォールでブロック」の確認が出たら「プライベートネットワーク」を許可してください
- この方法はオフライン用キャッシュ（Service Worker）が効かないので、PC側を止めると開けません。読み込んだコード・読書位置・しおりは iPad 側に残ります
- 保存データは開いたアドレスごとに別々です（A のファイル、B の localhost、公開版はそれぞれ独立）

## Android: Termux で clone / pull を簡単にする

`termux/` に、Termux 用の小さなスクリプトがあります。Termux で1回だけ次を実行してください。

```
curl -fsSL https://raw.githubusercontent.com/haru3ch/CodeViewer/main/termux/setup.sh -o setup.sh
bash setup.sh
```

途中で「clone したリポジトリを置くフォルダ」を聞かれます。すでに clone したリポジトリがあれば、その**1つ上のフォルダ**を答えてください。

| コマンド | すること |
|---|---|
| `pullall` | 置き場所の中のリポジトリを全部 pull（手元に変更があるものは飛ばす） |
| `cvclone <URL> [フォルダ…]` | 履歴を浅く clone。フォルダを指定すると、そこだけ取り出す |
| `cvlist` | 置き場所のリポジトリと、最新コミットの日時を一覧 |

**ワンタップで pull:** F-Droid から「Termux:Widget」を入れ、ホーム画面にウィジェットを置くと「全部pull」ボタンが出ます。

その他の小技: ↑キーで前のコマンドを呼び出す、Tab キーで名前を補完する、音量下ボタン＋キーで Ctrl（例: 音量下＋C で中止）。

## うまく動かないとき（デバッグ）

- スマホだけで調べる: アドレスの末尾に `?debug=1` を付けて開く（例: `https://haru3ch.github.io/CodeViewer/?debug=1`）か、⚙ 設定の「デバッグ表示」をオン。
  画面右上の 🐞（エラーがあると赤くなる）→「コピー」で、環境情報とログをまとめてコピーできるので、そのまま Claude に貼って相談できます
- PC で調べる: PC の Chrome で開き、F12 → 端末アイコンで iPad / スマホの画面を再現
- 実機を PC につなぐ: iPad は「設定 → アプリ → Safari → 詳細 → Webインスペクタ」をオンにして Mac の Safari の「開発」メニューから。Android は USBデバッグをオンにして PC の Chrome で `chrome://inspect`

## 公開（GitHub Pages）

`main` に `app/` の変更が入ると `.github/workflows/pages.yml` が Pages に公開します。
初回だけリポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。
公開URL: **https://haru3ch.github.io/CodeViewer/**

※ Pages のページ自体は誰でも開けますが、中身はアプリの画面だけです。読み込んだコードや APIキー は各端末の中にしかありません。

## 開発メモ

- ビルド不要の素の HTML / CSS / JS（ES Modules）。`app/` をそのまま静的配信すれば動く
- ローカル確認: `cd app && python3 -m http.server 8765` → http://localhost:8765/
- 外部ライブラリ（Anthropic SDK・highlight.js・marked・DOMPurify）は `app/vendor/vendor.js` に1ファイルでまとめて同梱。
  更新するときは `cd vendor-src && npm install && npm run build`
- `app/` を変えたら `standalone/code-reader.html` も作り直す: `cd vendor-src && npm run build:standalone`
- フォントを更新するときは `cd vendor-src && npm run build:fonts`
- アプリを更新したら `app/sw.js` の `VERSION` を上げる（端末のキャッシュを入れ替えるため）
