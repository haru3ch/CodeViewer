コード読解リーダー

端末に git clone したフォルダを選ぶと、ファイル一覧が表示されます。
行をタップして範囲を選び「解説して」を押すと、AIがその範囲を日本語で解説します。

読み込んだコードと APIキー はこの端末の中（ブラウザの保存領域）にだけ保存されます。
AIに質問したときだけ、そのファイルの内容が Anthropic の API に送られます。会社のコードは入れないでください。

行をタップして範囲を選び「解説して」を押してください。
選択なしで質問すると、ファイル全体についての質問になります。

フォルダの読み込み

ファイル数が多くて読み込みが遅いときは、ここに不要なフォルダ名を足すか、フォルダを選ぶときに読みたいサブフォルダだけを選んでください。

デバッグ

アドレスの末尾に ?debug=1 を付けて開いてもオンになります（?debug=0 でオフ）。
